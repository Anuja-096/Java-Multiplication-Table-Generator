# Java Multiplication Table Generator

## Description
A Java console application that generates multiplication tables for a single number or a range of numbers.

## Features
- Generates a multiplication table from 1 to 10.
- Generates tables for a user-defined range.
- Uses loops and a reusable method.
- Accepts user input using Scanner.

## Technologies Used
- Java
- Scanner
- For loops
- Methods

## How to Run
1. Compile Main.java using a Java compiler.
2. Run the program.
3. Select single-table or range-based generation.
4. Enter the requested number or range.

## Learning Outcomes
Practiced loops, nested loops, methods, user input, and formatted console output.
